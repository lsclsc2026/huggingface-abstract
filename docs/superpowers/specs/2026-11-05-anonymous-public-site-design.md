# 公开阅读站与匿名评论

用户已授权开始：面向国内熟人免费阅读、无需注册登录；匿名评论展示脱敏IP、基于IP的头像颜色和发送时间；隐藏待读、兴趣设置、相关度；小程序低优先级暂缓。

## 范围与实现选择

沿用FastAPI、SQLite、原生前端和单进程调度，不引入账户体系、GPU推理、向量库或新前端框架。模型生成保持统一、15分钟增量检查、16:00后成功导读固定。旧个人字段和笔记保留于原库，但不进入任何公开JSON、Markdown、历史统计或搜索响应，也不参与排序/计算。排序默认社区热度，ID作为稳定次序。

新增独立comments表，UUID标识、论文外键、正文、服务器UTC时间、脱敏IP、带密钥HMAC访客标识；不保存完整IP。每条评论含确定性头像色、匿名访客编号，北京时间前端展示。请求IP仅来自服务端可信request.client，不直接相信任意X-Forwarded-For。IP不是账户、NAT可共享、换网会改变标识。

评论正文纯文本1–1000字；分页每页最多50条；默认同IP15秒间隔、每小时20条，原子数据库事务限制，删除评论也不绕过发送频率。管理员可以删除评论；不做用户自行编辑、回复、点赞或通知。界面说明IP脱敏、颜色非身份标识及时间时区。

公开请求仅可阅读论文/导读/公开导出和发布评论。模型测试、重新加载、提取任务、旧个人修改、运行详情及管理员评论删除均需服务端Bearer管理令牌，缺少令牌配置时拒绝管理操作。公开页面不提供管理员令牌输入框，不暴露真实配置路径、密钥掩码、网关、用户兴趣或模型错误详情。令牌可来自环境变量或受权限保护的文件，管理通过SSH本地脚本操作。

保持PDF阅读/下载入口，避免访客触发无限外部下载：公开PDF接口重定向到已存论文的合法官方PDF地址，不公开本地缓存路径。个人缓存和旧管理端数据保留。

## 部署

新增Docker/Compose、HTTPS反向代理样例、持久化数据卷、自动恢复、健康检查、SQLite一致性备份/恢复说明。继续单应用worker，防重复调度；不必为小范围匿名站迁移PostgreSQL。

用户暂无域名或普通云服务器；现有AutoDL仅作个人验证。已核对其自定义服务协议限制科研自用、不得转发第三方链接，不将此入口用作公开站。购买服务器/域名另行由用户决定，不产生未授权费用。可先完成实现、验收和现有私有环境更新，公网DNS/证书和国内访问验收待实际资源落实。大陆对评论等功能的上线要求应核对，不能把开发验证等同于已允许公开运营。

## 验收

真实临时数据库验证旧库新增表不丢数据，所有公开响应和导出无私密字段，未授权管理请求不触发LLM/数据库写入；评论验证、未知论文、脱敏IPv4/IPv6、稳定颜色、转发头伪造、限流、分页和管理员删除。真实浏览器验证评论发布/重载、XSS仅作文本、移动布局、取消待读/相关度/设置入口。完整后端测试、JS语法、独立代码审查，Git分支提交/推送。公网未具备时明确记录未完成项。
